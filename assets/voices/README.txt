A THOUSAND DOORS (hub) — recorded voice lines
=============================================

Drop the generated .mp3 files in THIS folder. The hub prefers a recorded line
over browser TTS whenever the matching file is present, and falls back to TTS
for anything missing — so you can add them all at once or a few at a time.

HOW TO GENERATE THEM
  1. Open  ../../voice generator/voice-generator.html  in Chrome/Edge (over http).
     It auto-loads the hub script (two voices: ELARA and DR. VANCE).
     (To switch it back to Rift Keeper later, change the last line of that file
      from loadHubProject() to loadRiftProject().)
  2. Settings ⚙ → paste your Gemini API key (or pick another TTS provider).
  3. Click "Generate voices", then "⬇ Download all MP3s → assets folder" and pick
     THIS folder. Files are written with the exact names the hub loads.
  (Voices are editable in the cast table before generating.)
